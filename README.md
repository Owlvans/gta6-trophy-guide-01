Leonida Trophy Guide — an offline trophy tracker and platinum roadmap for Grand Theft Auto VI. All 55 trophies with their official names, descriptions and grades; a cited guide for each one, written in the guide's own words; a screened missable list (one potential missable, flagged with its Chapter 1 window); a spoiler shield that hides story trophies until they are earned; per-trophy counters for the long grinds; and progress that saves in the browser with export and import. No account, no network — the app runs entirely from its own files.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 — the app is fully offline
```
